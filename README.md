# Игра "Лабиринт" 🎮

Интерактивная игра для построения и прохождения лабиринтов с визуализацией алгоритмов.

## Возможности

### Генерация лабиринтов
- 🖱️ **Ручное построение** - создавайте лабиринт самостоятельно
- 🌲 **Алгоритм Краскала** - генерация с визуализацией
- 🔗 **Алгоритм Прима** - генерация с визуализацией
- 📏 **Настраиваемый размер** - от 5×5 до 30×30 клеток

### Темы оформления
- 🌸 **Весна** - свежие зеленые тона
- ☀️ **Лето** - яркие солнечные цвета
- 🍂 **Осень** - теплые оранжевые оттенки
- ❄️ **Зима** - холодные синие тона

### Прохождение лабиринта
- ⌨️ **Ручное управление** - стрелки или WASD
- 🤚 **Алгоритм правой руки** - автоматическое решение
- 🌊 **Волновой алгоритм** - поиск кратчайшего пути
- 👣 **Система следов** - визуализация пройденного пути

## Запуск проекта

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173) в браузере.

### Сборка для продакшена
```bash
npm run build
```

### Деплой на GitHub Pages
```bash
npm run deploy
```

## Технологии

- **React 18** - библиотека для создания интерфейса
- **TypeScript** - типизированный JavaScript
- **PixiJS v8** - 2D WebGL рендеринг
- **Vite** - быстрая сборка проекта
- **React Router** - маршрутизация

## Управление

- **↑ ↓ ← →** или **W A S D** - движение по лабиринту
- **Space** - пауза
- **R** - сброс позиции игрока
